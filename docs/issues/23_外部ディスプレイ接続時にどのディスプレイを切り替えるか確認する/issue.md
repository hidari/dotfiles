# 外部ディスプレイ接続時にどのディスプレイを切り替えるか確認する

## 背景

`home/.config/raycast/scripts/toggle-reference-mode.sh` は、プリセット popup を
「現在値が識別リストに含まれる最初の AXPopUpButton」で同定している。ディスプレイペインで
外部ディスプレイが選択されている状態は想定していない。

外部ディスプレイが Apple のリファレンス対応機 (Pro Display XDR / Studio Display) の場合、
プリセット名が識別リストと重なるため、内蔵ではなく外部のプリセットを黙って切り替える
経路がある。重ならない機種ならタイムアウトして明示的に失敗するので fail-safe だが、
重なる場合は誤った対象を切り替えて成功と報告する。

Issue #20 では内蔵ディスプレイのみの条件で live smoke を取った。前セッションが残した
「外部接続下では内蔵の popup が UI ツリーに現れないのではないか」という仮説のうち、
否定できたのは「内蔵のみでも失敗する」方向だけで、「外部接続下で誤対象を掴む」方向は
未検証のまま残っている。

## タスク

- [ ] 外部ディスプレイを接続した状態で現在の挙動を確認する
- [ ] 内蔵ディスプレイを対象として特定する手段があるか調べる
      (ペイン内でどのディスプレイが選択されているかを UI ツリーから判別できるか)
- [ ] 判別できないなら、外部接続時は失敗させるか対象を明示させるかを決める
