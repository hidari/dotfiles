# perf(test): gitleaks.bats の gitleaks 起動と範囲走査用リポジトリの組み立てをまとめる

## 背景

`scripts/tests/gitleaks.bats` はテストごとに一時ディレクトリを作り、fixture を 1 つ置いて gitleaks を
起動する。範囲走査のテストは、merge commit を含む使い捨てのリポジトリをそれぞれ組み立ててから走査する。

Issue 45 で gitleaks.bats は bats job (全スイート) でも走るようになった。PR #223 のマージ前レビュー
(efficiency の観点) が起動をまとめる余地を挙げ、CI で約 4〜5 秒の短縮と見積もった。この見積もりは
実測していない。

同じ手法 (setup_file で 1 回だけ走らせ、各テストはその結果を読む) は Issue 4 で nvim-markdown.bats に
当てた前例がある。

## 実測 (2026-09-17、開発機)

| 対象 | 値 |
| --- | --- |
| テストと起動の数 | 16 テストで、起動は 15 回 (`gitleaks dir` 12 / `gitleaks git` 3) |
| ファイル全体 (3 巡) | 2.96〜3.33 秒 |
| `gitleaks dir` 1 回 (小さな fixture、10 回) | 中央値 0.033 秒 (0.029〜0.089) |
| 範囲走査のテスト 3 件 (`bats --timing`) | 401〜622 ms |
| dir 走査のテスト 12 件 | 96〜160 ms |
| gitleaks を呼ばない配線テスト | 35 ms |

開発機で dir 走査の起動をまとめて削れるのは、12 回 × 約 0.03 秒で 0.4 秒前後にとどまる。範囲走査の
3 件は gitleaks の起動よりも使い捨てリポジトリの組み立て (git init と 3 コミットと merge) の比重が
大きいと見られるので、組み立てを 1 回にする方が効く可能性がある。組み立ての内訳は測っていない。

CI での値も測っていない。bats の TAP 出力は時間を持たないので、測るなら `--timing` 付きの実行が要る。
`scripts/ci/run-bats.sh` の bats 呼び出しに `--timing` を常設すれば、通常の run から取れる。
`--timing` を付けても skip の行は `# skip` を保つので、同スクリプトの skip 検出は効いたまま
(2026-09-17 に bats 1.14.0 で確認。CI も同じ版)。

## 決めること

- **やるか。**得られる時間は小さく、失うのはテストごとの終了コードという仕様の一部である。
  CI の `--timing` で得た dir 走査と範囲走査の時間から短縮の上限を見積もり、それがどれだけなら
  やるか (やめる基準) を、測る前に決める
- **検証の形が変わる。**今は各テストが gitleaks の終了コードと RuleID を見ている。1 回の走査に
  まとめると終了コードはまとめた走査全体で 1 つになり、各テストはレポートの File 単位で「自分の
  fixture に finding があるか / 無いか」を見る形になる。allowlist 側 (finding が無いことを確かめる
  テスト) は File で絞れば判定できるが、「終了コードが 0 になる」という仕様はそのままでは残らない。
  残すなら、通るべき fixture だけを別に 1 回走査するなどの形を決める
- **範囲走査のまとめ方。**3 件のうち 2 件は同じ形のリポジトリへ `-m` の有無だけを変えて走査し、
  3 件目は通常のコミットを 1 本足す。リポジトリを setup_file で 1 つ組んだうえで、次のどちらにするか
  - 走査は各テストが行う。終了コードの仕様が残るので、上の検証の形の変更と切り離せる
  - 走査も 2 回にまとめる。「`-m` が無いと見えない」の対照と通常コミットの finding が同じ
    レポートに混ざり、ここも File 単位の判定になる
- **テストの独立性。**結果を共有すると、ある fixture の変更が別のテストの判定へ波及しうる。
  fixture のファイル名をテストごとに分け、判定を File で絞ることで閉じられるか
- まとめた後も、ルールや allowlist を壊したときに各テストが個別に赤くなるか。あるテストの finding が
  別のテストの判定へ吸収されると、変異が観測できなくなる
