# docs: 言語規約が surface ごとに割れている

## 背景

CLAUDE.md はこのリポジトリの言語を「ログメッセージはシステム内部ログを日本語、フロント側など
外部に見えるものを英語。コード内のコメントは日本語」と定めている。ところが実装は surface ごとに
割れており、規約のどちらに属するのかが読み取れない面がある。

user CLAUDE.md が「読み手が誰かで決まるので、値を決めないまま書き始めると 1 つのリポジトリの
中で言語が混ざる」と警告している状態が、実際に起きている。

PR #183 のボーイスカウト掃きで見つけた。新規に足した `scripts/apm-guard/apm` の stderr を
英語にするか日本語にするかが、既存の規約から決まらなかったのが発端である。

## 実測 (2026-08-28)

日付付きのスナップショットとして扱うこと。判定は「文字列に仮名または漢字を含むか」で行った
機械的なもので、語彙レベルの精度は無い。

### シェル層のメッセージ

| 対象 | 件数 |
| --- | --- |
| `bootstrap.sh` の `log` / `warn` / `error` | 56 件中 4 件が日本語 |
| `home/.zshrc` の `echo` / `print` | 11 件中 7 件が日本語 |
| `scripts/backup-tool/backup` | 7 行に日本語 |
| `home/.claude/hooks/*.py` の判定文面 | 9 件が日本語 |

`bootstrap.sh` は「英語で統一されている」のではなく、英語だった層へ日本語が入りつつある。
日本語の 4 件は設定ディレクトリ共有と stale symlink 撤去という、いずれも後から足した機能に
集中している。

```
480: 設定ディレクトリ名として受け付けられない行を無視します
650: 別の場所を指すリンクがあるため projects の共有を skip します
657: 既存の実体があるため projects の共有を skip します (移行は手動)
784: 追加の設定ディレクトリがありますが設定ファイルが無いため stale symlink の撤去を skip します
```

### pytest のテスト名

20 ファイル 456 件のうち、日本語の名前を持つのは `test_pretooluse.py` の 18 件だけで、
このファイルは全件が日本語である。残り 19 ファイル 438 件は 0 件。

`scripts/tests/*.bats` 側には ast-grep ルール `bats-test-name-ascii-only` が既にあり、
テスト名を ASCII に縛っている。pytest 側には同じ規約が無い。

## 決めること

規約は既に CLAUDE.md にあるので、足すのではなく **surface を規約のどちらに割り当てるか**を
決める。

- `bootstrap.sh` と `.zshrc` が出すメッセージは「システム内部ログ」なのか「外部に見えるもの」
  なのか。読み手はこのリポジトリの利用者 1 名だが、リポジトリは PUBLIC である
- テスト名は「ログ」でも「コメント」でもない 3 つ目の surface である。bats 側の既存規約
  (ASCII のみ) を pytest へ広げるか、逆に日本語を許すか
- 決めたあと、機械検査を付けるか。付けないなら drift は続く

判断が割れる理由は読み手の想定にある。日本語の方が仕様として読みやすい面と、PUBLIC
リポジトリとして第三者が読む面が両方ある。どちらを取るかを 1 度決めれば、以後は迷わない。

## タスク

      テスト名 / コミットメッセージ / Issue 本文)

      surface があれば分類の方を足す
- [ ] 決定を CLAUDE.md へ書く。値の canonical を 1 箇所に保ち、散文で再掲しない
- [ ] 機械検査を付けるかを決める。付けるなら bats 側の `bats-test-name-ascii-only` と
      同じ ast-grep ルールの形が使えるか確かめる
- [ ] 既存の逸脱を揃える。`bootstrap.sh` の 4 件と `test_pretooluse.py` の 18 件が
      最小の対象
