# chore: 保留にしたタスクリスト統合 3 本を適用する

## 背景

Issue #10 でタスクリストを導出名へ寄せる移行を行ったが、統合 3 本を保留にした。移行先となる 2 つのリストを別の Claude Code セッションが同時に書き換えていたためである。

統合は「移行先の採番上限を読む → その値をオフセットにファイルを書く → 上限を更新する」という read-modify-write なので、読んでから書くまでの間に移行先へタスクが増えると採番が壊れる。

移行スクリプトは `.cache/migrate-task-lists.sh` にある (リポジトリ管理外)。`ONLY` 環境変数で 1 本ずつ処理できるよう直してあり、`.highwatermark` が実在する最大 ID より小さいことがある問題への対処も入れてある。この対処が無いと移行先の既存タスクを上書きする。

## タスク

- [ ] 他に Claude Code のセッションが動いていないことを確認する
- [ ] バックアップを取り直す (前回のものは移行前の状態なので古い)
- [ ] dry-run で残りの統合対象を確認する
- [ ] `ONLY` で 1 本ずつ適用し、各回で移行先の既存ファイルがハッシュ単位で変わっていないことを確認する
- [ ] 未完了タスクの subject 集合が保たれたことを確認する
- [ ] Issue #10 の未チェック項目を閉じる
