# CLAUDE.md の指示量と読む単位を減らす

## 背景

`home/.claude/CLAUDE.md` は全セッションへ常時ロードされる。
2026-08-17 時点で 314 行 / 45KB、さらに未コミットの追記が 199 行ある。
コミット履歴を見ると 2026-07-31 以降だけで 8 回のルール追記があり、増加は止まっていない。

問題は2層に分かれる。
層が違うので打ち手も違い、混ぜて 1 本の Issue にするとどちらの進捗を測っているのか分からなくなる。

層1: 1 ファイル内の構造。項目間に構造が無く、読むたびに全項目を舐める。これは Issue #24。

層2: ロード機構。ファイルが 1 枚しかないため、Rust のコードを触っていても Swift の規約を、git を触っていなくても push の作法を、常に全部払っている。Claude Code には `.claude/rules/*.md` + `paths` frontmatter による条件付きロードが実在し、これに載せ替えられる。これは Issue #36。

## 着手順序の依存

層1を先に片付ける必要がある。現行ファイルは「先述の `git push` ルールの一般形」「上の〜の裏面で、あちらは対象側、こちらは対照側」のような位置参照を多数含んでおり、ファイルを分割すると参照先が別ファイルへ飛ぶ。しかも壊れ方が沈黙で、リンク検査も lint も見ないため、分割後に気づく手段が無い。

Issue #24 の「位置参照を族名参照へ張り替える」タスクは、#36 の前提条件である。
