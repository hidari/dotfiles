# feat: 採否台帳で読む件を客観的な条件で絞りまとめて決められるようにする

## 背景

受け箱から仕分けた知見の候補は、採否台帳で815件ある (2026-11-11 時点)。97% が ISSUE-134 (446件)、ISSUE-133 (241件)、ISSUE-88 (106件) の3本に集まる。全件に要約・見立て・既存の規範との照合が付いているが、採否が決まったのは25件。仕分けは20日で8回あり、流入が判断を桁で上回っている。

ユーザーの申告 (2026-11-11): 見立てを信用しきれないので原文を読んでいることと、見立てを読んでも1件ずつ決める回数そのものが重いことの両方が効いている。印象では決めていないので1件に時間がかかる。ほかに、ときどきコンテキストが大きく増える感覚がある (原因は測っていない)。

読む件を誰が数えても同じになる条件で絞って残りは判断せずに保管し、確かめ済みのこととモデルの判断を見分けられるようにし、まとめて決められるようにする。設計は ISSUE-144-spec.md が持つ。
