# セキュリティの一次実測

`~/.claude/CLAUDE.md` の「攻撃者が使える面を最小に保ち防御を 1 層に頼らない」カテゴリが持つ規範の、手当ての詳細と一次実測。

規範の遵守そのものには要らない。手当ての具体が要るとき、規範を疑うとき、似た失敗を踏んで「これは既知か」を確かめるときに読む。

## charset 検証を名前空間の検証と兼用した事故

設定ファイルの行を `^\.[A-Za-z0-9._-]+$` で検証して eval へ流していた。

- `.git` は関数 `git` を生やして外部コマンドを shadow した
- `.claude-dev` は静的定義のランチャを潰した

どちらも charset を通っていて、警告も出なかった。

接頭辞を固定し、派生に使う接尾辞を予約することで塞いだ。
