# ホスト環境の一次実測

`~/.claude/CLAUDE.md` の「自分の作業でホスト環境を壊さない」カテゴリが持つ規範の、手当ての詳細と一次実測。

規範の遵守そのものには要らない。手当ての具体が要るとき、規範を疑うとき、似た失敗を踏んで「これは既知か」を確かめるときに読む。

## ホストでの大規模処理

fontTools の `TTCollection` で巨大な合体 TTC (Sarasa SuperTTC) を非 lazy 展開してメモリが 52GB まで暴走し、macOS を OOM で巻き添えに落とした。
無音を「ハング」と誤診して放置したのが増悪要因だった。

macOS の `ulimit -v` は address-space 制限が信頼できず、上限として当てにできない。
隔離先のコンテナには OrbStack か Docker を使う。
